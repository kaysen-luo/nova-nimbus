  • 可选背景层可加视差滚动(parallax) 增强纵深, 不强制

维度v2 飞机大战v3 人物守线

2.2.1 仇恨判定 · 4 阶优先级

BOBO 每次准备开火时按下列优先级选目标, 高阶优先级永远压过低阶; 同阶内 优先当前血量更少的敌人 (贯彻 "点残" 逻辑, 与恩赐解脱的 "点满" 互补)。

阶目标类型设计意图
P1正在攻击防线的敌人止血优先, 直接掐防线掉血源
P2Boss (大 BOSS / 小 BOSS)集火关键目标
P3精英怪压制策略型威胁
P4小兵兜底清场
  • 必须同阶内选血量更少者 (点残逻辑, 保证击杀效率)
  • 必须目标切换实时判定 (每帧或每次开火前重算), 允许在锁定后被更高阶目标抢占
  • 建议激光射线的视觉锁定过程 ≤ 0.1s, 避免视觉切换过于生硬

2.2.2 状态门对 BOBO 的作用方式 (与 §5 呼应)

  • 必须攻击力 / 攻速 / 暴击率 / 暴击伤害 4 项 → BOBO 直接全吃, 乘算到激光单次伤害 / 发射间隔上
  • 必须弹道 +N → 转化为 激光分叉 N 次: 打完主目标后按仇恨顺序自动跳打次优先级目标, 每次分叉不衰减 (与穿透卡不同)
  • 必须双倍火力 (来自火力静默翻转) → BOBO 同时发射 2 束激光锁 2 个目标, 分别按仇恨 P1 / P2 位取次优先级 (仇恨天然支持锁次优先级)
  • ⚠️ V3.3.6 修订: 双倍火力实际实现为 G.nuoStats.spd *= 2 (BOBO 激光发射攻速×2, 单目标), 非"2 束激光". 见 §V3.3.6 权威 — 本行历史描述保留供对比。
  • 必须火力静默 (未翻转的 debuff) → BOBO 静默 N 秒不发射激光 (原规则保留)

2.3 镜像 BOBO (v3.2 · 从宝箱池挪至无尽合成)

v3.2 定位变更: 镜像 BOBO 不再是宝箱产出, 从原宝箱库 6 号移除, 挪到 无尽模式合成宝箱 产出 (合成条件与获取方式待 §7.6 补细则)。同时把 "永久继承" 改为 持续 10s 临时召唤 型技能, 定位是短爆发而非全程双输出。
  • 必须获取渠道: 无尽合成宝箱 产出 (线性关卡 1-3 内不出)
  • 必须触发效果: 立即在主角左侧 0.5U 位置生成一个 镜像 BOBO, 继承本体 BOBO 当前 80% 属性 (攻击力 / 攻速 / 暴击率 / 暴击伤害 / 弹道分叉 / 双倍火力状态)
  • 必须持续时间: 10s, 到时自动消失, 不占永久栏位
  • 必须持续期间同吃状态门 (与本体 BOBO 同步刷新增益)
  • 必须持续期间主角横移, 镜像 BOBO 同步横移保持对称
  • 待定叠加规则: 持续期内再次抽到, 候选 A 延长 10s / B 刷新为满 10s / C 生成第 3 个 → 初版选 B 刷新

分 4 档 20 只, 每档功能位错开 (小兵消耗火力 / 精英引入策略应对 / 小 BOSS 集火转折 / 大 BOSS 关卡终局)。名字四字诀, 附美术提示词供外包 (荻子) 和 AI 生图使用。数值 (HP / 推进速度 / 攻击力 / 出现时机) 待美术定稿后单独填 art-spec-v3.html。

2.4.1 通用规则

  • 必须推进速度 慢于状态门(状态门会从敌人之间穿过到达主角)
  • 必须到达防线前 停下并攻击防线, 持续消耗防线持久度
  • 必须被击杀后立即消失, 不掉落物品
  • 必须4 档 20 只全部实装, 不允许砍档 (每档功能不可替代)
  • 建议美术风格: 卡通可识别, 独眼为主视觉锚点, 配色遵循「小兵冷色 → 精英暖色 → BOSS 混色」的渐进层次

§ 03 · 战场布局

双通道 2 : 3 空间几何

这是 v3 改造的物理基础。所有后续机制(状态门躲避 / 主角横移 / 子弹方向)都建立在这套空间几何上。

3.1 通道比例与单位换算

设屏幕宽度 = 5 个单位(后简称 U), 则:

  • 左通道(宝箱通道): 宽 2U, 占屏幕 40%
  • 右通道(接敌通道): 宽 3U, 占屏幕 60%
  • 主角 hitbox 宽度: 0.5U (含 BOBO 贴身, 实际有效宽度需考虑 BOBO 边缘)
  • BOBO 单体宽度: 0.3U
  • 状态门固定宽度: 接敌通道一半 = 1.5U
  • 防线高度: 屏幕底部约 1U 高的横向带

3.2 主角横移规则

规则说明
横移范围整个屏幕宽 5U 自由滑动, 含宝箱通道和接敌通道
纵向限制仅横轴移动, 不离开防线高度(主角守线职责)
BOBO 跟随所有 BOBO 与主角 刚性绑定同步横移

3.3 子弹方向规则

  • 必须主角和所有 BOBO 的子弹 始终垂直向上发射, 无论主角在哪个通道
  • 必须子弹位置由发射者当前 X 坐标决定 — 主角在宝箱通道 = 子弹打宝箱通道
  • 必须子弹不能跨通道(物理一致性)
临界情况 · 不抢行修正: 主角恰好骑在两通道分界线上时, 会出现 主角弹道在宝箱通道 + BOBO 弹道在接敌通道 的分裂状态。这是 feature 不是 bug, 代码不要做任何对齐 / 吸附 / 偏移修正, 让玩家自由利用这个边界位置做"边贪宝箱边守接敌"的精妙操作。
§ 04 · 宝箱通道(左) · v3.2 重写 · 三选一抽卡

技能升级卡 + 精通卡
Roguelike 混池抽卡

v3.2 起宝箱通道完全重构: 从 "8 件固定配件序列" 改为 三选一 roguelike 抽卡。卡池由 5 张技能升级卡 × 3 级 (串行解锁) + 20 张枪械精通卡 (§4.6 附录) 混合而成; 状态门只管平铺属性 (攻击力 / 攻速 / 弹道 / 暴击率 / 暴击伤害 / 双倍火力), 与宝箱的 "质变技能" 架构分离。

架构分离 (v3.2 顶层规则):
  • 状态门 = 平铺属性增益 (原规则保留, 补 BOBO 生效方式, 见 §5)
  • 宝箱 = 技能升级卡 + 枪械精通卡 混池三选一, 单卡一次性抽到即消耗
  • 宝箱 不影响 平铺 6 项数值 (那是状态门的领地), 只提供 质变 / 特殊触发 / 输出源强化

4.1 宝箱基础机制

  • 必须宝箱在通道内 冻结不动, 不自动下滑
  • 必须宝箱有血量, 被子弹击中累计伤害, 击破后 弹出三选一卡片界面 (期间敌人暂停 0.5s 缓冲, 与关卡节奏无缝衔接)
  • 必须玩家从三张卡中选一张, 立即结算 (若已 Lv3 满级则该技能卡不再进池; 精通卡若已持有, 权重 ×0.5, 见 §4.3 抽卡权重)
  • 必须宝箱通道内同时混入 障碍, 障碍击破不掉落任何东西 — 是纯粹的 "挡子弹" 消耗
  • 建议宝箱与障碍的视觉差异要明显, 颜色 / 形状 / 边框三层区分

  • 必须弹道后期几乎不出, 总增益压 +4 封顶 (即弹道类门单局最多贡献 +4, 累计到就不再刷弹道类)
  • 必须双倍火力 (火力静默翻转) 前中后期 概率平均
  • 必须固定攻击力 前期概率高, 百分比攻击力 后期概率高 (线性交叉)
  • 必须无尽模式 第 3 次攻击潮开始停刷 (给玩家一个成长上限), 前 2 潮不封顶

5.2 受击与数值变化

  • 必须子弹击中状态门 消耗子弹(子弹被门吸收, 不穿透)
  • 必须每颗子弹按 固定步进 改变门的数值(步进值在数值表定义, 不同门类型不同)
  • 必须数值变化方向 始终向"增益上限"方向: debuff 减弱 → 0 → 翻转 buff → 充满上限
  • 必须数值实时显示在门上, 颜色随状态变化 — 红(debuff) → 灰(0 中性) → 绿(buff)
  • 必须射击 只改数值, 不改宽度(门的物理尺寸始终 1.5U)

5.3 上限释放阻挡位

  • 必须数值达到 增益上限时, 门 释放阻挡位: 子弹可穿透打后面的敌人
  • 必须释放后门 不消失, 继续向下移动, 保持已达增益上限的状态
  • 必须释放后子弹 不再被消耗(穿透), 数值也不再变化(已达上限)
  • 建议释放后门的视觉变化要明显: 边框由实变虚, 或填充透明度下降

5.4 消失唯一条件

唯一消失条件: 状态门撞到主角, BOBO 吃到当前数值的 buff/debuff, 门 立即消失。
  • 必须"自然流出屏幕底部" 不 算消失 — 它要么撞主角, 要么被主角避开
  • 必须但当门移出屏幕底部时, 实际效果等同于消失(下个门可以生成)
  • 建议视觉上让"自然流走的门"轻微淡出, 区分于"被主角吃掉"的爆开效果

5.6 火力静默特殊维度 · 定义与规则 (v3.1 新增)

命名逻辑: "火力静默" 是 减益维度描述词 — 名字本身指代 debuff 效果. 通用规则 "减益为正数, 增益为负数" 在此维度成立.
  • 必须火力静默门 初始数值 = +4s (减益, 状态色 红), 表示 BOBO 吃到后会静默 4 秒
  • 必须玩家射击门, 数值 递减: +4s → +3s → +2s → +1s → 0s → -1s (增益翻转点)
  • 必须数值到 -1s 时门变增益, 状态色 绿, 效果为 双倍火力 1s (含义: BOBO 吃到后火力翻倍, 持续 1 秒)
  • 必须状态色变化 作用于门体本身, 不作用于 BOBO / 主角 (BOBO 只在门被吃时才生效果)
  • 建议因为火力静默是 唯一数值方向与其他维度相反的门 (其他维度 debuff 是负数, buff 是正数), UI 上可用小图标标注避免玩家混淆

  • 收益: 可以击破宝箱拿武器, 子弹打宝箱通道目标

关系 C · 故意撞门 (主动吃 buff/debuff)

6.3 临界场景 · 门居中"针尖挤过"

当状态门位置恰好让接敌通道左右两侧的躲位都 < 主角宽 0.5U 时(理论极端: 门居正中, 两侧各 0.75U), 操作上能挤过去但极险。

§ 07.5 · v3.1 新增 · 预体验关卡

7.6.4 分数公式 · 均衡 (D13 拍板)

决策: C 均衡方案, 存活时间 + 防线 HP + 杀敌数 三者都要兼顾, 逼玩家平衡"活久 vs 打多"。

分数 = 存活时间(秒) × 5 + 剩余防线 HP × 2 + 累计杀敌数 × 5
  • 存活时间权重 5: 主导因素, 撑得越久分越高
  • 防线 HP 权重 2: 低权重, 但撑到最后 HP 还很高可以拉分
  • 杀敌数权重 5: 主导因素, 逼玩家主动打怪, 不能只守不打混时间
反 exploit 设计意图: 单一维度主导 (纯存活 / 纯击杀) 会被玩家挖出捷径 (比如只守不打拖时间)。均衡公式使玩家必须兼顾"活久 + 打多", 天然形成策略深度; 且"综合分"比"单一数字"更适合截图分享。
