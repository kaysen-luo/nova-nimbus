§ 03 · 战场布局

双通道 2 : 3 空间几何

这是 v3 改造的物理基础。所有后续机制(状态门躲避 / 主角横移 / 子弹方向)都建立在这套空间几何上。

3.1 通道比例与单位换算

设屏幕宽度 = 5 个单位(后简称 U), 则:

  • 左通道(宝箱通道): 宽 2U, 占屏幕 40%
  • 右通道(接敌通道): 宽 3U, 占屏幕 60%
  • 主角 hitbox 宽度: 0.5U (含 BOBO 贴身, 实际有效宽度需考虑 BOBO 边缘)
  • BOBO 单体宽度: 0.3U
  • 状态门固定宽度: 接敌通道一半 = 1.5U
  • 防线高度: 屏幕底部约 1U 高的横向带

  • 必须子弹位置由发射者当前 X 坐标决定 — 主角在宝箱通道 = 子弹打宝箱通道
  • 必须子弹不能跨通道(物理一致性)

§ 04 · 宝箱通道(左) · v3.2 重写 · 三选一抽卡

技能升级卡 + 精通卡
Roguelike 混池抽卡

v3.2 起宝箱通道完全重构: 从 "8 件固定配件序列" 改为 三选一 roguelike 抽卡。卡池由 5 张技能升级卡 × 3 级 (串行解锁) + 22 张枪械精通卡 (§4.6 附录) 混合而成; 状态门只管平铺属性 (攻击力 / 攻速 / 暴击率 / 暴击伤害 / 火力静默 / 防线三维), 与宝箱的 "质变技能" 架构分离。

架构分离 (v3.2 顶层规则):
  • 状态门 = 平铺属性增益 (原规则保留, 补 BOBO 生效方式, 见 §5)
  • 宝箱 = 技能升级卡 + 枪械精通卡 混池三选一, 单卡一次性抽到即消耗
  • 宝箱 不影响 状态门的平铺属性维度 (那是状态门的领地), 只提供 质变 / 特殊触发 / 输出源强化

4.1 宝箱基础机制

  • 必须宝箱在通道内 冻结不动, 不自动下滑
  • 必须宝箱有血量, 被子弹击中累计伤害, 击破后 弹出三选一卡片界面 (期间敌人暂停 0.5s 缓冲, 与关卡节奏无缝衔接)
  • 必须玩家从三张卡中选一张, 立即结算 (若已 Lv3 满级则该技能卡不再进池; 精通卡若已持有, 权重 ×0.5, 见 §4.3 抽卡权重)
  • 必须宝箱通道内同时混入 障碍, 障碍击破不掉落任何东西 — 是纯粹的 "挡子弹" 消耗。V3.3 障碍机制: 真宝箱落定后 20s 未击破 → 前方 (靠防线侧) 随机刷 0-2 个障碍 (HP = 最近真宝箱 × 0.5), 同列正下方。
  • 建议宝箱与障碍的视觉差异要明显, 颜色 / 形状 / 边框三层区分

4.2 技能升级卡池 · 5 张 × 3 级 · 隐藏串行解锁

5.2 受击与数值变化

  • 必须子弹击中状态门 消耗子弹(子弹被门吸收, 不穿透)
  • 必须每颗子弹按 固定步进 改变门的数值(步进值在数值表定义, 不同门类型不同)
  • 必须数值变化方向 始终向"增益上限"方向: debuff 减弱 → 0 → 翻转 buff → 充满上限
  • 必须数值实时显示在门上, 颜色随状态变化 — 红(debuff) → 灰(0 中性) → 绿(buff)
  • 必须射击 只改数值, 不改宽度(门的物理尺寸始终 1.5U)

5.3 上限释放阻挡位

  • 必须数值达到 增益上限时, 门 释放阻挡位: 子弹可穿透打后面的敌人
  • 必须释放后门 不消失, 继续向下移动, 保持已达增益上限的状态
  • 必须释放后子弹 不再被消耗(穿透), 数值也不再变化(已达上限)
  • 建议释放后门的视觉变化要明显: 边框由实变虚, 或填充透明度下降

5.4 消失唯一条件

唯一消失条件: 状态门撞到主角, BOBO 吃到当前数值的 buff/debuff, 门 立即消失。
  • 必须"自然流出屏幕底部" 不 算消失 — 它要么撞主角, 要么被主角避开
  • 必须但当门移出屏幕底部时, 实际效果等同于消失(下个门可以生成)
  • 建议视觉上让"自然流走的门"轻微淡出, 区分于"被主角吃掉"的爆开效果

命名逻辑: "火力静默" 是 减益维度描述词 — 名字本身指代 debuff 效果. 通用规则 "减益为正数, 增益为负数" 在此维度成立.
  • 必须火力静默门 初始数值 = +4s (减益, 状态色 红), 表示 BOBO 吃到后会静默 4 秒
  • 必须玩家射击门, 数值 递减: +4s → +3s → +2s → +1s → 0s → -1s (增益翻转点)
  • 必须数值到 -1s 时门变增益, 状态色 绿, 效果为 双倍火力 1s (含义: BOBO 吃到后火力翻倍, 持续 1 秒)
  • 必须状态色变化 作用于门体本身, 不作用于 BOBO / 主角 (BOBO 只在门被吃时才生效果)
  • 建议因为火力静默是 唯一数值方向与其他维度相反的门 (其他维度 debuff 是负数, buff 是正数), UI 上可用小图标标注避免玩家混淆

§ 06 · 躲门空间几何

主角与状态门
3 种关系判定

状态门宽 1.5U + 接敌通道宽 3U, 意味着主角在接敌通道内本来就有躲门空间, 不必每次都横跨到宝箱通道。这套几何决定了核心操作手感。

项数值说明
接敌通道宽3U右通道全宽
状态门宽1.5U固定一半
剩余空间1.5U接敌通道内可用于躲门的横向余量

6.2 三种主角 vs 门的关系

关系 A · 接敌通道内绕门 (主要躲门方式)

  • 门在接敌通道左半 → 主角滑到接敌通道右半
  • 门在接敌通道右半 → 主角滑到接敌通道左半
  • 这是 70%+ 场景的默认躲法, 不消耗"贪宝箱"机会

关系 B · 横跨宝箱通道躲门 (顺便贪)

  • 门在接敌通道正中, 接敌通道两侧躲位都不够宽时
  • 或玩家主动想拣宝箱时
  • 代价: 接敌通道弹道空缺, 防线进入警告状态(§4.4)
  • 收益: 可以击破宝箱拿武器, 子弹打宝箱通道目标

关系 C · 故意撞门 (主动吃 buff/debuff)

  • 门已被打到 S4 上限释放 → 主动撞 → BOBO 吃满 buff
  • 或决定吃当前数值(不等满)时主动撞
  • 或紧急情况下不得不撞(没有更好选择)

6.3 临界场景 · 门居中"针尖挤过"

当状态门位置恰好让接敌通道左右两侧的躲位都 < 主角宽 0.5U 时(理论极端: 门居正中, 两侧各 0.75U), 操作上能挤过去但极险。

设计决策: 保留这个 针尖挤过 的高难操作, 不做碰撞箱宽容判定。这是 endless 类游戏的"操作天花板", 留给硬核玩家炫技。

§ 07 · 防线与失败条件

持久度归零 = Game Over

7.1 防线规格

属性规格
位置屏幕底部, 横跨整个屏幕宽 5U
高度约 1U 高度的横向带

视觉反馈持久度低于阈值(如 30%)时整条防线红色脉动

7.2 敌人攻防交互

  • 必须敌人到达防线前 停下, 不继续推进
  • 必须敌人开始 持续攻击, 每秒消耗一定持久度(不同敌人 dps 不同)
  • 必须敌人仍可被子弹击杀, 击杀后立即停止攻击
  • 建议多个敌人同时攻击时, 防线消耗 dps 叠加
  • 可选敌人攻击时有特效(冲撞 / 啃咬 / 射击), 美术自由

7.3 失败后的嘲讽接口

预留 嘲讽接口给买量素材制作, 不影响主玩法:

  • Game Over 瞬间触发 嘲讽 Boss 角色弹窗(可关闭, 不强制)
  • 嘲讽 Boss 出现位置: 屏幕中央, 类似竞品的真人脸特写
  • 文案库: 可配置, 例如 "守不住了吧" / "外星人请客了" / "再来一局?"
  • 视觉接口预留: 美术后续可替换为任意 IP 形象(原创嘲讽角色 / 真人脸 / 卡通形象)
  • 实现位置: 单独配置文件 taunt_config.json, 与游戏主逻辑解耦
§ 07.5 · v3.1 新增 · 预体验关卡

预体验关卡

7.6.4 分数公式 · 均衡 (D13 拍板)

决策: C 均衡方案, 存活时间 + 防线 HP + 杀敌数 三者都要兼顾, 逼玩家平衡"活久 vs 打多"。

分数 = 存活时间(秒) × 5 + 剩余防线 HP × 2 + 累计杀敌数 × 5
  • 存活时间权重 5: 主导因素, 撑得越久分越高
  • 防线 HP 权重 2: 低权重, 但撑到最后 HP 还很高可以拉分
  • 杀敌数权重 5: 主导因素, 逼玩家主动打怪, 不能只守不打混时间
反 exploit 设计意图: 单一维度主导 (纯存活 / 纯击杀) 会被玩家挖出捷径 (比如只守不打拖时间)。均衡公式使玩家必须兼顾"活久 + 打多", 天然形成策略深度; 且"综合分"比"单一数字"更适合截图分享。

② 障碍触发规则:
  • 触发前提: 通道中至少 1 个宝箱 obstacleDelay 走完 (=20s 未受任何伤害)。无满足条件的宝箱则完全不刷。
  • 计时: 宝箱落定 (settledAt) 即起, 任意伤害 (含 AOE) 重置 (通过 lastHitAt 判)。
  • roll: 满足前提时 roll 一次 Math.random() < 0.5:
    • false → R 内所有宝箱重置计时, 不刷障碍
    • true → 只刷 1 个障碍 (不是每箱各刷)
  • 障碍位置: 从该列未被占用的空槽随机选 1。该列无空槽 → 不刷, R 统一重置。
  • 插入后自动推挤: reflow 时宝箱按 A→F 重排, 障碍前方的箱被顶到 F 方向。

  • 伤害永久削上限 (关键): 每次受 X 伤害, hp 和 maxHp 都 -X, 保证 hp ≤ maxHp 恒成立。
