§ 01 · 视角与世界观

一点透视 · 守线人视角

1.1 视角

  • 必须一点透视斜俯视: 摄像机俯角 30-40°, 远端通道收窄, 形成纵深感
  • 必须仍为 2D 渲染: 不引入 3D 引擎, 用 2D 透视技巧(梯形通道 + 远小近大缩放) 实现伪 3D
  • 可选背景层可加视差滚动(parallax) 增强纵深, 不强制

1.2 题材与节奏

维度当前口径
玩家角色主角 + AUV, 站定底部防线
敌人动线从顶部推进, 直到防线前停下攻击
节奏类型endless wave 塔防 (守 = 主旋律)
失败条件防线持久度归零
核心张力"贪宝箱 vs 守防线" 双轨决策
设计意图: 被动守线 + endless 节奏, 玩家不追求"打到尽头", 而是"撑多久"的存活叙事, 契合 A 路单机休闲爆款 30-60s 单局节奏。

1.3 世界观

近未来 · 星际殖民时代 · 地球殖民星 Aurelia 争夺战。严肃科幻底 + 缝隙反差萌为核心调性锚, 后续 UI 文案 / 立绘 / 音效外包统一遵循。

1.3.1 世界设定

维度设定
时代近未来 · 星际殖民时代 · 地球主导的殖民网络已延伸至邻近星系, 但殖民星资源开采尚在建设期
冲突地点地球殖民星 Aurelia — 因蕴藏地球独缺的 Aurelium 金属 (超导/曲率引擎核心材料) 而成为殖民网络重心
冲突起因外星文明侵入 Aurelia, 目的是掠夺 Aurelium 矿脉, 非通讯友好接触
防御体系Aurelia 殖民星外围部署星际防卫队防线, 由两人小队 + AI 辅助作战单元组成的机动战斗单元把守矿区通道
玩家所在位Aurelia 前线防线 · 两人守线小队 · 负责阻断外星生物突入殖民城与矿区

1.3.3 AI 辅助作战单元 (AUV) · 军方标配型号 AUV-0

星际防卫队为每位星际战士配发一台 AI 辅助作战单元 (系统代号 AUV, 玩法系统层通名)。型号统一为 AUV-0 (Auxiliary Utility Vehicle · 0 号原型机), 双主角持有同一军方标配型号, 差异只体现在各自给自己的 AUV 取的名字与语言习惯上, 面板数值与玩法机制完全一致。

  • 玩家昵称层 = 零指导 (Marvis) / 手术刀"寸厘" · 简称寸厘 (Nova) — 场上口语 / 无线电台词
设计意图: 系统层通名保持稳定, 未来即使调整型号命名或增加新型号, 也无需触碰代码和玩法文档。反差萌接缝: 同一军方标配 AUV-0, 两个人给它取了完全不同的名字 (调侃式尊称 vs 手术器械代称), 讲的是主角性格差, 不用台词点破。

1.3.4 外星生物 · Ossyr (厄司)

维度设定
命名由来Ossyr = 拉丁词根 os (骨) + -yr 造词后缀 · 中文名 厄司 · 首次目击于 Aurelia 殖民星矿区外围, 因骨甲外壳与结晶义肢改装形态得名 · 侵略性凶残 · 与 Aurelia / Aurelium 共拉丁词根, 三者一致性拉满
形态基调生物本体 + 外星骨甲/结晶义肢改装 · 严禁机械金属/塑料元素 · 基础/精良/稀有三档以骨甲覆盖率 20% / 50% / 80% 分层, 稀有档配结晶能量核
五官骨甲盔下发光单眼隙缝 (紫/绿/蓝三阵营色) · 关节缝隙同色透光, 表现"生物能量透出骨甲"
死亡表现杂兵/精英直接消失 (从简, 不做爆炸/尸体/掉落特效, 只留短促飘字与音效) · Boss 以上死亡时冻结定格 + 去色 + 渐隐 (强调击杀分量, 避免与杂兵同表现)
行为逻辑从顶部推进 · 直至防线前停下攻击 · 详见 §3 战场布局
调性锚 · 严肃科幻底 + 缝隙反差萌 (给美术/音效/文案外包统一遵循)
  1. 硬核设定 + 软名字/软文案: 军方型号 AUV-0 (硬) + 场上叫"零指导"/"寸厘"(软, 双主角各自取名); AUV 医疗玩家时 UI 提示可以偶尔跳戏 (如"正在敷云朵形创可贴")。
  2. 外星生物的硬核压迫感: 叙事上是入侵者, 视觉上是生物本体 + 骨甲/结晶义肢改装的异种战士 (严肃硬核), 死亡从简不做浮夸表现。这条不再承担反差萌, 归严肃底; 反差萌接缝改由"AUV 硬名软名"和"双主角吐槽"两条支撑。
  3. 双主角吐槽接缝: 关卡切换 / Boss 出现 / 通关 等节点插 2-3 秒无线电短对话 (文本弹幕即可, 无需过场动画), 严肃战报 + 战友日常吐槽的化学反应是留存钩子。
反面示例: 全程搞怪滑稽 (削弱严肃底, 观感掉档) · 完全严肃无接缝 (与竞品同质化, 传播弱)。反差萌是缝隙里冒出来的, 不是主基调。

1.3.5 无线电台词 · 双主角画外音 (WIP)

WIP 玩家上场的角色 = 场上执行方, 未上场的角色 = 无线电画外音 (纯文本弹幕形态), 在关卡节点触发短对话, 承担 (a) 告知玩家游戏进度 (b) 调节战场气氛 (c) 双主角叙事延展 三重作用。

调性总则 (Kaysen 2026-07-27 定死, 起草时逐条比对):
  • 不提 AUV / 型号 / 昵称: 台词内容层不出现 AUV / AUV-0 / 零指导 / 寸厘, 保持世界观纯度
  • 称呼规则 (2026-07-27 K 立死):
    • Nova → 马启航: 严格单一称呼"马启航" (无变体, 不用"Marvis"/"老马"/"启航"/"马哥"等)
    • 马启航 → Nova: 严格单一称呼 "灵主任" (医生职业敬称保留)。K34-A 起, 无线电场景 = 无情播报机, 无情绪切换, 无名字变化
    • 档案层名字 (§1.3.2) 保持 马启航 Marvis / 牛知灵 Nova 双名格式不动 — 世界观档案层与台词层解耦
  • 平视战友, 非粉丝仰视: 不出现 "姐"、"磕一个"、"给你请客" 这类谄媚话术
  • 战时严肃感为底: 一方上场 + 另一方后方联络的定位, 严肃指挥语言优先, 反差萌只从缝隙冒
  • 外星生物统一称"目标": 派生 "目标群" / "高价值目标" / "锁定目标" 等, 不用"泡泡罐子""汽水"等花名
  • 载体 = 纯文本弹幕: 屏幕角落飘字, 不做头像/对话框/语音

§ 03 · 战场布局

双通道 2 : 3 空间几何

这是所有后续机制(状态门躲避 / 主角横移 / 子弹方向)的物理基础。

3.1 通道比例与单位换算

设屏幕宽度 = 5 个单位(后简称 U), 则:

  • 左通道(宝箱通道): 宽 2U, 占屏幕 40%
  • 右通道(接敌通道): 宽 3U, 占屏幕 60%
  • 主角 hitbox 宽度: 0.5U (含 AUV 贴身, 实际有效宽度需考虑 AUV 边缘)
  • AUV 单体宽度: 0.3U
  • 状态门固定宽度: 接敌通道一半 = 1.5U
  • 防线高度: 屏幕底部约 1U 高的横向带

§ 04 · 宝箱通道(左) · 三选一抽卡

技能升级卡 + 精通卡
Roguelike 混池抽卡

宝箱通道采用 三选一 roguelike 抽卡。卡池由 5 张技能升级卡 × 3 级 (串行解锁) + 22 张枪械精通卡 (§4.6 附录) 混合而成; 状态门只管平铺属性 (攻击力 / 攻速 / 暴击率 / 暴击伤害 / 火力静默 / 防线三维), 与宝箱的 "质变技能" 架构分离。

架构分离 (v3.2 顶层规则):
  • 状态门 = 平铺属性增益 (原规则保留, 补 AUV 生效方式, 见 §5)
  • 宝箱 = 技能升级卡 + 枪械精通卡 混池三选一, 单卡一次性抽到即消耗
  • 宝箱 不影响 状态门的平铺属性维度 (那是状态门的领地), 只提供 质变 / 特殊触发 / 输出源强化

4.1 宝箱基础机制

  • 必须宝箱在通道内 冻结不动, 不自动下滑
  • 必须宝箱有血量, 被子弹击中累计伤害, 击破后 弹出三选一卡片界面 (期间敌人暂停 0.5s 缓冲, 与关卡节奏无缝衔接)
  • 必须玩家从三张卡中选一张, 立即结算 (若已 Lv3 满级则该技能卡不再进池; 精通卡若已持有, 权重 ×0.5, 见 §4.3 抽卡权重)
  • 必须宝箱通道内同时混入 障碍, 障碍击破不掉落任何东西 — 是纯粹的 "挡子弹" 消耗。真宝箱落定后 20s 未击破 → 前方 (靠防线侧) 随机刷 0-2 个障碍 (HP = 最近真宝箱 × 0.5), 同列正下方。
  • 建议宝箱与障碍的视觉差异要明显, 颜色 / 形状 / 边框三层区分

4.2 技能升级卡池 · 5 张 × 3 级 · 隐藏串行解锁

  • 必须固定攻击力 前期概率高, 百分比攻击力 后期概率高 (线性交叉)
  • 必须无尽模式 第 3 次攻击潮开始停刷 (给玩家一个成长上限), 前 2 潮不封顶

5.2 受击与数值变化

  • 必须子弹击中状态门 消耗子弹(子弹被门吸收, 不穿透)
  • 必须每颗子弹按 固定步进 改变门的数值(步进值在数值表定义, 不同门类型不同)
  • 必须数值变化方向 始终向"增益上限"方向: debuff 减弱 → 0 → 翻转 buff → 充满上限
  • 必须数值实时显示在门上, 颜色随状态变化 — 红(debuff) → 灰(0 中性) → 绿(buff)
  • 必须射击 只改数值, 不改宽度(门的物理尺寸始终 1.5U)

5.3 上限释放阻挡位

  • 必须数值达到 增益上限时, 门 释放阻挡位: 子弹可穿透打后面的敌人
  • 必须释放后门 不消失, 继续向下移动, 保持已达增益上限的状态
  • 必须释放后子弹 不再被消耗(穿透), 数值也不再变化(已达上限)
  • 建议释放后门的视觉变化要明显: 边框由实变虚, 或填充透明度下降

5.4 消失唯一条件

唯一消失条件: 状态门撞到主角, AUV 吃到当前数值的 buff/debuff, 门 立即消失。
  • 必须"自然流出屏幕底部" 不 算消失 — 它要么撞主角, 要么被主角避开
  • 必须但当门移出屏幕底部时, 实际效果等同于消失(下个门可以生成)
  • 建议视觉上让"自然流走的门"轻微淡出, 区分于"被主角吃掉"的爆开效果

  • 门在接敌通道右半 → 主角滑到接敌通道左半

  • 或玩家主动想拣宝箱时

  • 收益: 可以击破宝箱拿武器, 子弹打宝箱通道目标

  • 或决定吃当前数值(不等满)时主动撞

7.6.3.5 大 BOSS 出现规则 (v3.2 更新)

Kaysen 拍板 (2026-07-07 / 2026-07-08 更新): 大 BOSS 作为常规 3 关的末终 BOSS 出场, 玩家在通关主线时至少会遇到 3 次。无尽模式下大 BOSS 按段递增涌入, 后期可能同屏多只。
  • 必须常规关卡: 每关末 (关卡 1/2/3 结尾) 出 1 只大 BOSS, 击败后关卡通过
  • 必须无尽模式: 大 BOSS 出现频率按段递增, 与段结构对齐 (段 1 稀疏, 段 5 密集)
  • 必须无尽模式通关率目标 ≤ 1%: 玩家死亡的正常路径是回合内清不完敌人累积到崩溃, 不允许被单只大 BOSS 一击秒
  • 必须大 BOSS 阵型的段间引入节奏必须让玩家撑不住 — 不是难以击杀单只, 而是杀不过来 (数量压倒火力上限)
  • 待定大 BOSS 具体 spawn 曲线 (每段每潮出几只, 同屏上限) 由数值组 T07 细化 · 建议起始曲线:
    • 段 1 (适中): 0 只 · 让玩家熟悉小兵/精英节奏
    • 段 2 (较大): 1 只 / 段 · 出现在第 4-5 潮, 作为段末压力测试
    • 段 3 (困难): 2-3 只 / 段 · 与系统节奏切换同步施压, 每 2 潮出 1 只
    • 段 4 (地狱): 4-5 只 / 段 · 潮内可能同屏 2 只
    • 段 5 (叹息之壁): 6+ 只 / 段 · 潮内可能同屏 3 只, 是压倒火力的核心
难度曲线守则: 无尽模式的失败方式必须是"被时间/数量磨死", 不是"被单只 BOSS 一击秒". 玩家死时应该觉得自己努力过 (打了很久, 但敌人越来越多, 最终撑不住), 而不是觉得被作弊 (突然一只怪跳出来一击必杀).

7.6.4 分数公式 · 均衡 (D13 拍板)

决策: C 均衡方案, 存活时间 + 防线 HP + 杀敌数 三者都要兼顾, 逼玩家平衡"活久 vs 打多"。

分数 = 存活时间(秒) × 5 + 剩余防线 HP × 2 + 累计杀敌数 × 5
  • 存活时间权重 5: 主导因素, 撑得越久分越高
  • 防线 HP 权重 2: 低权重, 但撑到最后 HP 还很高可以拉分
  • 杀敌数权重 5: 主导因素, 逼玩家主动打怪, 不能只守不打混时间
反 exploit 设计意图: 单一维度主导 (纯存活 / 纯击杀) 会被玩家挖出捷径 (比如只守不打拖时间)。均衡公式使玩家必须兼顾"活久 + 打多", 天然形成策略深度; 且"综合分"比"单一数字"更适合截图分享。

7.6.5 好友榜 · 微信开放数据域 (D13 拍板)

决策: B 方案, 走微信开放数据域 — 免费、微信原生 API, 好友之间对比自己 vs TA 的最高分。

  • 必须无尽模式结算面板显示 好友榜 top 10, 高亮玩家自己的位置
  • 必须破纪录时弹出 荣誉横幅 (独立设计, 金色 + 缩放呼吸动画 + 大事件音), 参考 skill html5-minigame-polish-pipeline 荣誉成就规范
  • 建议结算面板加"分享到微信"按钮 (可选), 用微信原生分享 API, 图片带分数展示
  • 可选陌生人全球榜不做 — 休闲游戏留存意义不大, 且需要自建服务器
技术选型理由: 微信开放数据域是白嫖社交的最佳解 — 0 服务器成本, 用微信关系链好友的比较自然产生比拼欲, 参考《向僵尸开炮》同款架构。集成时多加一个开放数据域子包 (微信文档有现成模板)。
