v3.1 · 总纲视角原则

🎥 v3.1 核心视觉原则 (所有资产必读) 本作是 守线塔防 · 一点透视斜俯视。"玩家视角" ≠ "角色朝向玩家", 而是 玩家和主角同视线, 一起看向敌人来袭的方向。这决定了所有资产的朝向。

1. 摄像机位

  • 摄像机位于主角右后上方, 俯角 40-50° 加强俯视 (v3.1 二次修订 2026-07-03)
  • 画面深处是远方地平线 (敌人来袭方向), 画面前方是防线 (玩家守卫方向)
  • 参考经典塔防守线视角: 皇室战争 / Kingdom Rush / Bloons TD 系列

2. 角色朝向对照表

资产类型朝向玩家看到

3. 光源方向 (v3.1 修订)

主光源统一: 画面右上 45° (与摄像机同侧, 从"右后上方"打下)。 背视角角色 (主角 / NUO) 的高光落在角色的右后肩 / 右后上方, 玩家能看到高光边缘; 正面朝下的敌人 高光落在头顶 / 后脑, 玩家从上方俯视也能感受立体感。

为什么改右上不再是左上: v1 时代是俯视视角, 光源方位相对随意; v3 定为背视角后, 光源必须 和摄像机同侧 (右后上方), 否则背影所有高光都落在看不见的一面, sprite 会失去立体感变成剪影。

4. 背视角角色的"表情传达"方法论

核心难题: 背视角看不到脸, "反差萌" (兴奋 / 委屈 / 警觉) 情绪怎么传达?

3 个信号通道 (从主到辅):
  1. 肢体语言 (主角): 肩膀高度 + 头部倾角 + 站姿重心 + 手部动作
  2. 发光元件颜色变化 (NUO): 底部悬浮光晕 + 侧透弧 + 后脑 LED 亮度
  3. 侧脸微表情 (主角): 右侧脸颊轮廓 + 右耳位置微调, 辅助不主导
不要试图: 让角色频繁扭头看镜头 (破坏"守线专注感") / 让 NUO 变成"卡通眼球" (破坏机械感)。

5. 视角原则的例外情况

  • 过场 CG / 加载画面: 不受此原则约束, 可自由构图 (可以正面英雄式立绘)
  • 结算画面 / 死亡画面: 摄像机可临时切侧视 / 环绕, 强化情绪
  • UI 头像 / 图鉴插图: 可用正面立绘 (与游戏内 sprite 是两套独立资源)
  • 剧情立绘 (未来 P2): 遵循传统正面/侧面立绘规范, 不受本纲约束

CHAPTER 04主角 + NUO 系统

📌 v3 玩法核心 v3 的玩家角色不再是飞机,而是 主角 (人物) + NUO (悬浮球辅助机器人) 的双体组合。 主角站在屏幕底部防线上方,左右滑动横移; NUO 贴身右侧同步横移; 拿到镜像 NUO 后, 对称位置出现一个紫色镜像球,组成 三体火力。这是 v3 的核心反差萌钩子。

4.1 主角 (人物本体)

P0 PNG 序列 hero_main
ID: HERO-001

设计描述

主角是一个站岗守线的"打工人物"风格,带科幻感的战术装备 (头盔/护甲/能源背包), 体型偏写实但脸部表情有反差萌的卡通化处理 (大眼睛/委屈/警觉/兴奋)。 站姿守线,不操作武器,武器自动开火。设计参考: Halo 士兵 + 蛋仔派对萌系角色 的中间态。

🎥 视角 (v3.1 修订) 主角的 sprite 是 3/4 背视角: 摄像机位于主角右后上方 30-40° 俯拍, 玩家看到的是主角的背影 + 右侧一点点脸颊轮廓 + 右耳。角色朝向画面深处 (正对远方来袭方向)。 参考: 皇室战争 / Kingdom Rush / 塔防守线类经典视角。

反差萌钩子改由肢体传达: 背视角看不到正脸, 所以 "兴奋" / "委屈" 等表情 不再通过面部完成, 改为 肩膀高度 + 头部倾角 + 站姿重心 3 个信号:
  • 兴奋 (excited): 肩膀微耸 + 头部微仰 5° + 双脚微踮
  • 委屈 (worried): 肩膀下垂 + 头部微低 5° + 重心后移
  • 警觉 (idle 变体): 肩膀稳定 + 头部微前伸 + 双脚微向前压重心
右侧脸颊轮廓可辅助传达一点点表情 (如兴奋时颧骨微抬), 但不作主要信号。
